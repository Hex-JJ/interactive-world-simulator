# 互动世界模拟器

这是一个无需安装、无需插件的通用互动世界模拟提示词。

把提示词复制到豆包、DeepSeek、ChatGPT、Claude 或其他聊天模型的新对话中，即可开始一段自由输入、后果持续存在的互动世界体验。

## 通用版：无需安装

打开 [通用互动世界模拟器提示词](通用互动世界模拟器提示词.md)，复制全部内容到任意 AI 聊天模型的新对话中发送。

模型会先询问书名或世界名。你也可以直接输入：

```text
《全职法师》；我想扮演莫凡，从天澜魔法高中举行魔法觉醒的那天开始。
```

通用版包含三种体验模式、自由输入行动、持续状态、NPC 独立行动、世界线偏离与存档读取。

进入已有作品时，通用版默认采用“原著氛围·平行体验”：原著主线作为世界背景继续，玩家拥有独立路线；只有时间、地点、任务、资源、组织或危机真正交汇时，才可能结识原著人物。具名角色可以直接开局，模型会使用广为人知的设定、人物印象与日常场景增强代入感，但不承诺逐条考据；玩家可随时用“纠正：……”覆盖与自己记忆或所选版本冲突的设定。关键秘密、未来事件、隐藏能力和重要资源不会直接剧透或白送。若你想严格贴合某一版本，请提供 2—5 句角色/阶段简报，并注明小说原著、具体改编版或“不限定版本”。

## 核心体验

- 玩家控制尝试，世界根据能力、资源、信息、时间、地点与他人反应结算结果；
- 资源、损耗、关系、承诺、已知事实与后果持续存在；
- NPC 与组织有独立目标，不能读心；
- 原著未来只是基线；玩家与主线人物的交汇必须有现实因果，关键前提改变后不强制回归剧情；
- 爽玩模式奖励好计划，但不白送关键资源、能力或信任；
- 世界只加载当前有关的少量系统，例如竞争交易、力量成长、都市关系或学院组织；
- 存档只保留角色已知事实，新对话读取后不恢复已消耗资源。
